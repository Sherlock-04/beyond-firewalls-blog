# Beyond Firewalls: The Age of Autonomous Defense

> *When machines learn to attack and defend, who wins the cybersecurity arms race?*

An editorial research publication and interactive web blog designed for **GitHub Pages**. This essay explores the dynamics of machine-speed adversarial AI, the emerging arms race between automated attackers and autonomous defenders, and why enforceable boundaries are essential when AI becomes both the weapon and the shield.

---

## 🌟 Features

- **Cyber-Editorial Design**: Bespoke dark & light themes, glowing cyber mesh, and responsive typography powered by *Space Grotesk*, *Inter*, and *JetBrains Mono*.
- **Interactive AI vs AI Simulation**: Step through an attack-defense cycle (stolen credentials, anomalous lateral movement, autonomous token revocation, and automated micro-patching) directly in the browser.
- **Threat Vector Breakdown**: Deep-dive analysis of Prompt Injection, Data Poisoning (Microsoft Tay case study), and Excessive Permissions.
- **Architectural Safeguards Visualizer**: Direct side-by-side comparison of fragile prompt instructions (*intent*) vs enforced access-control IAM boundaries (*policy*).
- **Dynamic Reading Utilities**: Real-time reading progress bar, active Table of Contents (scrollspy), word count & read time metrics, font-size adjustment, and 1-click clipboard sharing.
- **Zero-Build Deployment**: 100% pure HTML5, modern CSS3, and vanilla ES6 JavaScript. Runs natively on GitHub Pages with `.nojekyll`.

## 🚀 Live on GitHub Pages

To activate this blog on GitHub Pages:

1. Push this repository to your GitHub account (e.g., `main` branch).
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Select the **main** branch and **/(root)** folder, then click **Save**.
5. Your publication will be live at:
   ```
   https://<your-username>.github.io/beyond-firewalls-blog/
   ```
